# 可访问性检查

## 基线

对变更触及部分可检查：
- 表单控件有可用 label；
- focus 状态可见；
- 交互控件支持键盘导航；
- disabled 和 loading 状态正确；
- button 和 link 语义正确；
- dialog 有焦点管理和关闭行为；
- 状态/错误文本对用户可见；
- 不只用颜色表达状态。

## 深入检查场景

当变更影响以下范围时，可加强可访问性评审：
- 导航；
- 表单；
- dialogs；
- 表格；
- 重键盘操作工具；
- 公共页面；
- 设计系统组件。

自动化可访问性检查有帮助，但不充分；相关场景应结合键盘操作和屏幕语义评审。
