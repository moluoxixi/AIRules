# Handoff（会话交接）

## 触发条件

- 用户说"交接""handoff""换会话""写个 handoff""上下文要满了"
- 用户主动要求切换 agent 或中断当前任务

## 不适合场景

- 任务已完成并交付 → 直接收口，不需要 handoff
- 仅是临时暂停 → 不需要 handoff

## 输出

在项目根目录输出 `handoff.md`（覆盖上一份），内容必须包含：

```markdown
# Handoff — <简短任务标题>

## 当前状态
<正在做什么，进行到哪一步>

## 已完成
<已交付的事项，一行一条>

## 未完成 / 下一步
<具体的下一个动作，让新 agent 可以直接接手>

## 未决项（MISSING / 待确认）
<尚未解决的关键事实、等待用户确认的决策>

## 关键文件
<新 agent 必须先读的文件路径，一行一条>
```

## 约束

- 不得写入 `vendor/`、`node_modules/`、`.git/`
- 文档用事实陈述，不附加解释或安慰语句
- 长度控制在能被新 agent 一次读完的范围内
