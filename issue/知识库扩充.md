# 统一知识目录契约实现计划

## 背景

当前项目文档分散在 docs/ 下，外部知识无标准入口。本计划将长期项目知识统一到 `knowledge/`，与 `openspec/` 同级：OpenSpec 承载变更/规格/计划，knowledge 承载长期背景事实。编排在任务初始化时 diff 检测 `knowledge/` 是否有变更：有变更则先触发 organize-knowledge 整理，再读取；无变更则直接读取。

## 核心决策

- 统一目录：knowledge/，废弃 docs/
- 子目录中文命名，按需创建
- index.md 是编排唯一入口
- **不提供同步 skill**：用户自行决定文档怎么进来
- **organize-knowledge skill**：无 description（不自动加载），由编排 diff 触发或用户手动调用
- **编排初始化 hook**：任务启动时 diff knowledge/ → 有变更先整理再读取，无变更直接读取
- 本项目 docs/ 迁移到 knowledge/
