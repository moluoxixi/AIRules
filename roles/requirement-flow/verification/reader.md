## 实际启动的样例

使用 `__test__/prepare_reader_example.py` 从保留的库存、预约、维修快照组装临时项目；业务入口来自 `__test__/reader-example/docs/business/`，关联任务仍为样例原有的 Markdown 记录。

```bash
python3 roles/requirement-flow/__test__/prepare_reader_example.py --output /tmp/requirement-flow-reader-example
python3 roles/requirement-flow/skills/requirement-flow/scripts/reader.py \
  --project /tmp/requirement-flow-reader-example --entry docs/business/index.md \
  --tasks inventory/docs/copy-decision.md --tasks library/docs/changes --port 8765
```

核验地址为 `http://127.0.0.1:8765/`；复核时须先运行上述命令。核验结束停止服务并清理本次临时项目，不将该临时地址当作已经部署的网站。样例均为合成资料，R12/R13 不代表本次实测过的真实生产环境。

## 内置浏览器实际观察

使用 IAB 打开真实服务，桌面视口 1280×900、移动视口 375×812，另检查默认窄窗口。临时视口覆盖结束后已恢复。

视觉复用 requirement-flow 历史 light 主题的纸色、深青灰、朱砂及楷体标题、Optima/苹方字体。显式 gap、margin、padding 使用 0/4/8/12/16px；1280px 和 375px 视口实测头部到首个筛选区均为 16px。导航占位、两端对齐、滚动预留和图表内部坐标按结构尺寸核对；移动任务卡的可见控件计算间距没有超过 16px。
