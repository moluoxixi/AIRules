# 文档布局与本地搜索验收

2026-11-27，本地候选。参考 [Element Plus 文档站](https://element-plus.org/zh-CN/component/button.html)的导航组织，沿用现有水墨主题和不超过 16px 的页面间距，没有引入其组件框架。

## 最终行为

- 顶部固定搜索和主题切换，大标题随正文滚动；左侧业务/任务目录独立滚动并保持当前项。
- CSS 宽度 ≥1280px 时显示 200px 右侧标题目录；960–1279px 保留左栏，将本页目录折叠到正文前；更窄时左栏成为抽屉，本页目录仍可展开。
- 本页目录复用 Markdown 渲染产生的标题和唯一锚点，点击跳转，滚动标出当前章节；分类筛选同步隐藏其他章节的目录项。滚动高亮不改 URL。
- 关联、依据与读取信息按需展开；搜索和任务列表不生成伪标题，原图页也不把 iframe 内部结构当作 Markdown 目录。
- MiniSearch 7.2.0 随离线资产分发，在浏览器内对当前正文与原任务标题分词、排序。中文使用 Intl.Segmenter，标题优先，英文可匹配前缀与轻微拼写错误，短契约码不做模糊匹配。

索引每次由当前核验过的文本派生，没有持久搜索库或独立服务。目录摘要与正文不同版或正文移除时排除该正文并提示刷新；索引不成为业务内容源。
