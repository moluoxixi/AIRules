# product role

产品角色资产包含从 PM/product 方法论复制的一方 skill：

- deliver-prd
- deliver-user-stories
- deliver-acceptance-criteria
- deliver-edge-cases
- develop-adr
- develop-solution-brief

当前只建立 product skills；rules、mcp、hooks、agents 暂未按产品角色拆分。

同步 product 角色时会默认叠加 `roles/common/`，因此仍包含公共的会话索引 hook 与手动会话沉淀 / 提炼 / 记忆能力。
