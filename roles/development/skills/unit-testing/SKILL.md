# 单元测试（后端/纯逻辑）

为纯逻辑与后端代码编写单元测试，落实单测点矩阵。

## 触发条件

- 实现后端服务、业务逻辑、数据访问、工具函数
- 需要按单测点矩阵覆盖正常路径、边界、异常分支

## 不适合场景

- 前端组件交互/UI → 用 `interaction-testing`
- 跨服务真实集成验证 → 属集成测试，单测用 mock 隔离
- 测试用例的设计 → 由 `test-design` 承担

## 编写要点

- **正常路径**：每条验收用例对应的预期返回与副作用
- **边界**：空集合、零值、极大/极小、临界值
- **异常分支**：非法入参、依赖失败、超时、并发冲突
- **mock 隔离**：外部依赖（DB、网络、时钟、随机）以 mock/stub 隔离，保证测试确定性与速度
- **断言充分**：断言行为与关键状态，而非仅断言"没抛异常"

## 输出边界

- 测试覆盖以单测点矩阵为准；覆盖不足时补有效测试或说明原因，不得删断言、放宽断言或写无意义测试。
- 优先项目既有测试框架与约定；缺失时按项目语言生态标准选型。
- 必须实际运行测试并读取结果，不得假设通过。
