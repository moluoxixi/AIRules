# 交互测试（前端）

为前端组件与交互流程编写测试，落实交互场景矩阵。

## 触发条件

- 实现前端组件、页面、交互、表单、状态流转
- 需要按交互场景矩阵覆盖用户操作与各状态态

## 不适合场景

- 纯后端逻辑 → 用 `unit-testing`
- 纯视觉像素级还原 → 属设计走查，不在本 skill 范围
- 测试用例的设计 → 由 `test-design` 承担

## 编写要点

- **组件交互**：点击、输入、提交等操作触发的预期渲染与回调
- **表单校验**：合法输入通过、非法输入给出预期校验反馈
- **状态流转**：加载态、成功态、空态、错误态的渲染与切换
- **空错态**：无数据、请求失败、超时的用户可见反馈
- **关键 E2E**：贯穿多组件的核心用户旅程，按项目既有 E2E 工具编写

## 输出边界

- 测试覆盖以交互场景矩阵为准；覆盖不足时补有效测试或说明原因，不得删断言或写无意义测试。
- 优先项目既有测试/E2E 框架与约定；缺失时按项目前端生态标准选型。
- 必须实际运行测试并读取结果，不得假设通过。
